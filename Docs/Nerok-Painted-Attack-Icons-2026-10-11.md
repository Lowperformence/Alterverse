## Assets and integration

- Runtime images: `Assets/Alterverse/Resources/CyberShark/Icons/0.png` through `4.png`.
- Each opaque RGB PNG is 1254 × 1254 pixels. The existing Unity importer still caps runtime texture size at 256, uses bilinear filtering and clamp wrapping, and disables mipmaps.
- Preserve all existing texture GUIDs and importer files. `AbilityButtonView` already loads these exact resource paths for Nerok and uses the whole image cell.
- Preserve the existing circular HUD shader, cooldown sector, unavailable treatment and ultimate trim. No gameplay, balance, animation or other hero assets change.
- Prompts: `Tools/CyberShark/icon-prompts.json`. Generated with the built-in image_gen tool; the legacy Nerok icon contact sheet supplied the anchor/material reference.
- Preview: `ArtSource/Heroes/CyberShark/attack_icons_preview.png`. Top row shows full art; bottom row shows 64px circular normal, 50% cooldown and unavailable states. This is a CPU preview of the current shader, not a Unity screenshot.
- The preserved Blender source and renderer describe the legacy geometric artwork. The renderer now defaults to `ArtSource/Heroes/CyberShark/LegacyAttackIcons`, so rerunning it does not overwrite the painted HUD art. Explicit `NEROK_ICON_OUTPUT` overrides remain available for intentional comparisons/restoration.
