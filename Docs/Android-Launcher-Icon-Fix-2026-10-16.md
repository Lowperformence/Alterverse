# Android launcher icon repair

The Android adaptive icon slots previously contained only the original logo in layer zero. Android's second layer was not assigned, allowing the Unity foreground to appear over the game's logo. The release helper used the older application-icon API and accepted any nonempty slot, so it did not repair the missing foreground.

`AndroidLauncherIcons` assigns all adaptive backgrounds and foregrounds with `SetPlatformIcons`. The project targets Unity 6000.6, where `AndroidPlatformIconKind.Round` and `.Legacy` are obsolete with compilation errors; the helper accesses only the supported `.Adaptive` kind and requires only its two textures. The existing build callback applies the repair before every Android build, including development builds and builds started through Unity's standard window. Release validation checks every adaptive slot and its expected textures. The repair is also available under `DIMENSIONS FRONT > Release > Repair Android launcher icons`.

The original `DimensionsFrontAppIcon.png` remains unchanged. A mechanical SVG layout export adds safe padding and masks the light outer corners of its existing rounded frame. The adaptive foreground's 216px square fits inside the central 66/108 safe circle on a 512px canvas; the opaque background fills the complete canvas. The older legacy export remains available as unused artwork and is no longer loaded by the repair or release validation. The original source is only 128px; exporting at 512px does not add artwork detail.

Regenerate derived images with Node.js and `sharp`: `node Tools/Branding/export-launcher-icons.cjs`.

Validation completed: adaptive texture GUID references, PNG dimensions, alpha coverage, circular safe area, unchanged source hash, round/rounded-square preview and whitespace checks. The regression fixture reproduces Unity 6000.6's obsolete-as-error declarations: the previous helper failed with the same four CS0619 errors seen in the user's editor. The corrected production helper compiles and passes checks for all six adaptive slots, layer order, incomplete layers, stale Unity textures, validation, idempotence, missing textures and unavailable icon slots, without requiring legacy artwork. Run `python Tools/Branding/Regression/run.py --dotnet-root <dotnet-sdk-directory>`. These fixtures are not a Unity integration test. Unity and the Android toolchain are unavailable here, so no APK/AAB or device test was performed.

The relevant upstream source files were read from `Lowperformence/Alterverse`, `dev/vertical-slice`, commit `bab893aa435d3a58d44e68869f946326c36fd504`. This change is limited to Android launcher icons and their build configuration. Existing local matchmaking edits were not modified.

The GitHub update is the preferred installation path. The optional `DimensionsFront-Icon-Fix.unitypackage` imports only the three derived icon textures and the repair helper through `Assets > Import Package > Custom Package`; it does not replace ProjectSettings, release build configuration or gameplay code. After a manual package import, run the Repair Android launcher icons menu. Installing a new game build is required before the phone's launcher can show the repaired icon.

API references: [Unity 6000.6 supported Android icon kinds](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityeditor/android/androidplatformiconkind), [Unity platform icons](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/PlayerSettings.SetPlatformIcons.html), [Android adaptive icon design](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).
