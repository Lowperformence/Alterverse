# Planet surface details

All eleven environments have distinct ground and stone detail maps, generated by `Tools/PlanetSurfaces/build_surface_details.py` with Blender and NumPy. The generator also produces an editable Blender material study and `ArtSource/PlanetSurfaces/SurfaceStudy.png`.

The 512px repeatable maps pack signed slope in RG, roughness in B, and centered height in A. They are numerical data, imported linear RGBA32 with mipmaps and streaming on desktop and Android. Each active ground/stone pair uses approximately 2.67 MiB including mipmaps. Existing palette and lighting remain in the shaders. Diamond Core receives subtle facet detail through its transparent crystal shader.

`PlanetSurfaceMaterials` loads the current planet's authored assets, falling back to generated data only if missing. Imported assets are never destroyed by the material owner. The Unity editor validation checks all 22 maps, Android formats, and shader errors before builds.

Validation: run `python Tools/PlanetSurfaces/validate_surface_assets.py` with NumPy and Pillow. All 22 maps passed channel variation, slope orientation, dimensions, unique asset identity and importer checks. Unity compilation, shader compilation and on-device visual/performance checks must still be run in Unity.
