# Hero concept provenance

The original AI-generated PNGs in `Archive` are preserved byte-for-byte, including their embedded C2PA content credentials. File hashes and observed action timestamps are recorded in `Archive/provenance.json`. The pipeline has not performed cryptographic signature validation. The exact historical prompts were not saved as repository files; that limitation is explicitly recorded.

The full-roster pass covers Zhaev Null, Auren Kest, Sivra Quell, Ione Vaska, Tahla Venn, Brakk Orun, THE TRAVELER, Nerok Abyss and Andromeda Timmy. Each new concept will retain its complete prompt, existing-model reference, original image, image hash and subsequent model revision.

Existing shapes, anatomy and rigs are inherited project inputs. The project's `Tools/HeroRebuild/README.md` declares Human Base Meshes 1.4.1 to be a CC0 anatomy source; the full-roster documentation will collect the vendor notice alongside that declaration. Concept generation does not retrospectively establish authorship or licensing of inherited files. The archive documents the actual creation process and does not make an exclusivity guarantee.
