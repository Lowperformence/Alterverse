# Pyraxis mechanical scorpion

Original segmented machine body, red panels, eight articulated legs with piston rods, broad cutting pincers and seven-segment needle tail. Uses the existing scorpion movement pivots, with one skinned renderer replacing the prototype geometry. Gameplay remains owned by HotZoneTank.

Rebuild with `python Tools/MechanicalScorpion/build_mechanical_scorpion.py` (NumPy/Pillow). Resource coordinates are local to named rig pivots. Mesh indices, bounds and finite coordinates validated; exact front/back geometry previews reviewed. Unity animation and device performance still need verification.
