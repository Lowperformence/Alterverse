# Noxara clockwork spider

Original brass/copper mechanical arachnid with eight articulated rod legs, exposed gears, green reagent cylinder and needle-like feet. The existing planted-foot IK owns movement; original mesh renderers are hidden synchronously and replaced with one skinned mesh. The translucent vessel retains its brass cage.

Rebuild with `python Tools/NoxaraClockworkSpider/build_clockwork_spider.py` (NumPy/Pillow). Finite geometry, indices and bone-path mapping checked; exact offline front/back previews reviewed. Unity and mobile verification remain pending.
